# 営業日カレンダーメーカー

このリポジトリは、無料ツール「営業日カレンダーメーカー」の公開ページそのもの(https://uuhai0625.github.io/eigyobi-calendar/ )です。
入力した内容をどう処理しているか、誰でも確認できるように公開しています。外部への送信はアクセス解析(Google Analytics)のみで、入力した内容は送っていません。
祝日は内閣府「国民の祝日について」の一覧(2026年・2027年分)を使っています。
